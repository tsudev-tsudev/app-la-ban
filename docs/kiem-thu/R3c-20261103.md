## 2. Đo từng bước

Analytics Engine ghi thêm `doubles` theo bước (`src/thuan/do-tre.ts`): double1 tổng (giữ nghĩa cũ), double2..8 =
`chan` (D1 danh sách chặn), `rlIp` (binding), `phien` (D1 phiên), `nonce`, `gioiHan`, `luuTru` (KV / R2 / cache),
`d1` (D1 của handler), double9 = isolate lạnh; blob5 = colo. `Date.now()` trong Worker chỉ nhảy khi có I/O nên mỗi số là
thời gian CHỜ I/O thật. Đo lại bất kỳ lúc nào: `./tools/thu/do-tre-ae.sh prod 24` (nạp `cf.env` bằng `set -a`).

Kết quả trên staging (colo **SIN**, bản chỉ thêm đo):

- D1 primary APAC: 5-15 ms mỗi truy vấn (kể cả isolate lạnh). D1 KHÔNG phải nghi phạm chính; bật read replication
  không giúp (primary đã ở APAC).
- **Durable Object: ~485 ms cố định mỗi lần một isolate chạm một DO lần đầu** (tra vị trí DO), lặp lại cả với DO đã
  tồn tại và còn ấm. Lưu lượng thưa -> isolate mới liên tục -> gần như mọi yêu cầu trả giá này cho DO giới hạn tốc độ
  (theo IP / thiết bị x route) + DO nonce, `/v1/events` thêm DO PhongSoc (SOC realtime). Khi chạm DO đã biết: 7-15 ms.
- KV nguội (`/v1/config`): ~190-240 ms; R2 `latest.json` nguội: ~185 ms.
- `/v1/health` p50 213 ms ở prod = truy vấn D1 danh sách chặn khi đệm isolate (3 s) trống.

## 3. Thay đổi

1. Nonce chống phát lại + thách thức S2 + giới hạn tốc độ theo route: **DO -> D1** (migration `0011_dem_d1.sql`,
   `0012_bo_chi_muc_dem.sql`; `src/thuan/dem-d1.ts`). `goiNonce` giữ nguyên chữ ký. D1 một primary tuần tự hoá ghi ->
   khoá chính bảo đảm nonce dùng đúng một lần. Cron 5 phút dọn dòng hết hạn (`donDem`).
2. Route có xác thực: nonce + luật theo thiết bị trong **một** batch D1 (một lần ghi / yêu cầu ký).
3. Route công khai chỉ đọc (`/v1/config`, `/v1/web/cau-hinh`): Rate Limiting binding `RL_DOC_CONG_KHAI` (60 / phút / IP,
   không ghi D1) + gói cấu hình qua Cache API colo (`docQuaColo`, TTL bằng `cacheTtl` KV cũ).
4. `/v1/events`: Threat Engine tách `ghiSuKien` (đọc song song + ghi sự kiện) đồng bộ, phần rule / điểm / SOC realtime
   chạy `waitUntil` sau phản hồi. Quyết định chặn vẫn ở server, áp từ yêu cầu kế tiếp như trước.
5. `/v1/health` không chạm D1 (IP bị chặn ở prod vẫn bị WAF List chặn trước Worker).
6. `/v1/status`: `latest.json` qua Cache API colo. `/v1/session/refresh`: ghi IP chung batch xoay phiên.

DO `KhoNonce` / `GioiHanToc` giữ binding một bản để rollback, bỏ ở bản sau (expand -> contract).
